# saneee.in brand kit

Everything you need to make something that looks and sounds like saneee.in: a website edit, an Instagram post, a reel, an ad or a proposal.

These files follow the **live website** (www.saneee.in, `src/app/globals.css`). If an older document disagrees (for example the 2026 draft that used Syne, Inter and Space Mono), this kit wins.

## The brand in ten lines

1. Name: **saneee.in**, always lowercase, three e's, with the `.in`.
2. A web design and software studio in Mumbai.
3. Line: *Designed to be distinguished.*
4. Four colours: Ink `#080808`, Paper `#F6F6EF`, Lime `#C7FF2E`, Grey `#5F5F5A`. Each team member also has an accent: Param lime, Teesha pink `#FF80EC`, Hardik orange `#FB6F2B`, Smit yellow `#FFDC69`.
5. Lime is the loud one. Use it on purpose, not everywhere.
6. Two worlds: **sane** (paper and ink, calm) and **insane** (lime, loud).
7. Type: the custom **Saneee Brand** face, plus **Instrument Serif Italic** for voice lines.
8. The logo's i has a cursor arrow for a dot. The **sigil** is the S with that arrow.
9. Write short. Talk to the business owner. No agency fluff.
10. Buttons are pills. Panels are almost square (4px corners).

```

├─ README.md            this file

├─ LOGO.md              wordmark and sigil use

├─ AI-CONTEXT.md        one file to paste into an AI tool

├─ tokens.json          the same values for Figma, Canva or code

└─ assets/
   ├─ logo/             wordmark SVGs (transparent and on a background)

   ├─ png/              ready-to-use PNG exports
   └─ fonts/            Saneee Brand .otf (desktop) and .woff2 (web)
```
